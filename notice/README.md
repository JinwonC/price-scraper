# 첫 화면 공지

제품 목록 맨 위에 뜨는 공지다. 프로모션, 샘플 마감, 라이브 안내처럼 그때그때
알려야 하는 것을 **구글 시트에 한 줄 쓰면** 사이트에 올라간다.

시트: **d'Alba 크리에이터 사이트 — 공지** · `공지` 탭
`https://docs.google.com/spreadsheets/d/1Ehdw8YErocgOxf6rb0zaU0kRmehplw1AGCkZFOaqPRk/edit`

| 칸 | 뭘 쓰나 |
| --- | --- |
| 표시 | `Y` 면 올라가고 `N` 이면 안 올라간다. 지우지 말고 N 으로 바꿔 두면 다음에 다시 쓴다 |
| 제목 | 굵게 한 줄 |
| 본문 | 여러 줄 써도 된다. 줄바꿈은 그대로 나온다 |
| 링크 | 누르면 열릴 주소. 비워도 된다 |
| 링크문구 | 링크 버튼에 쓸 말. 비우면 '자세히 보기' |
| 시작일 · 종료일 | `2026-11-02` 꼴. 비우면 계속 뜬다. 기간이 지나면 저절로 내려간다 |
| 비고 | 사람끼리 보는 칸. 사이트에는 안 나간다 |

## 두 길로 올라간다

1. **시트를 직접 읽는다.** 화면이 열릴 때 시트를 csv 로 받아 온다. 시트에 쓰고
   새로고침하면 바로 보인다 — 배포가 필요 없다.
   이 길이 열리려면 시트를 **'링크가 있는 모든 사용자 · 뷰어'** 로 한 번 바꿔 둬야
   한다(공지 문구만 들어 있는 시트다). 안 바꾸면 2번만 작동한다.
2. **매일 한 번 구워 둔다.** 1번이 막혔을 때를 대비해, 매일 갱신 때 시트 내용을
   `web/data/notice.json` 에 넣고 배포한다. 이 경우 시트에 쓴 내용은 다음 날
   올라간다.

```bash
# 시트 값을 커넥터로 받아 JSON 으로 저장한 뒤
python3 notice.py <받은.json>      # → ../web/data/notice.json 의 '공지' 칸
```

## 급할 때

지금 당장 올려야 하는데 시트 공유가 아직 안 돼 있으면, 클로드에게 공지 내용을
말하면 바로 커밋해 올린다(배포까지 5~10분).
