# 브랜드 라이브 일정 → 사이트

사내 'Schedule' 시트의 브랜드 자체 라이브 일정을 사이트의 `/live` 화면으로 옮긴다.
어필리에이트 크리에이터가 브랜드 라이브와 겹치지 않게 방송을 잡는 데 쓴다.

## 하루에 한 번 갱신하기

시트는 커넥터(MCP)로 읽는다. 스크립트가 바로 부를 수 없어서, 받은 값을 JSON 으로
떨어뜨려 두고 스크립트에 넘긴다.

```
# 1) 'Schedule' 탭의 A~E 열을 받는다 (F 열 GMV 계획은 받지 않는다)
#    mcp__Google_Sheets__get_values(
#      spreadsheetId="1qdmKPYxh3QbAyeBXifFbkQH10YAYB1VQJ14mmqJ1wXU",
#      range="Schedule!A1:E300")
#    받은 응답을 그대로 파일로 저장한다 ({"values": [...]} 꼴)

python3 schedule.py <받은.json>      # → ../web/data/live-schedule.json

# 2) 사이트를 다시 빌드해 배포한다
cd ../web && npm run build
```

## 무엇을 싣고 무엇을 빼나

읽는 칸은 A 날짜 · B 계정 · C 시작 · D 종료 · E 예정 시간이다.
**F 열(GMV 계획)은 읽지 않는다.** 매출 목표라 싣지 않는다 — 이 저장소는 공개다.

지난 일정은 담지 않는다. 피해서 잡는 데 쓰는 화면이라 오늘부터가 쓸모다.

## 시간대

시트의 시작·종료 칸에는 `2026/11/05 12:00 (EDT)` 처럼 꼬리표가 붙어 있는데,
**11월 1일부터 동부는 EST 라 꼬리표가 실제와 맞지 않는다.** 그래서 꼬리표는 읽지
않고, 적힌 시각을 뉴욕 현지 시각으로 보고 그 날짜의 동부 규칙으로 UTC 로 바꾼다.
JSON 에는 UTC 만 들어가고, 화면에서 고른 시간대(동부·중부·산악·태평양·알래스카·
하와이)로 그때그때 다시 적는다. 서머타임이 끼는 날은 줄마다 EDT/EST 꼬리표가
자동으로 붙는다.

## 날짜가 어긋난 줄

시트에 날짜 칸과 시작·종료 칸의 날짜가 다른 줄이 있다(한 주를 안 밀고 복사한
자리). 날짜 칸을 믿고 시각만 옮겨 적되, JSON 에 `확인필요` 를 달아 화면에
'날짜 확인 중' 으로 표시한다. 스크립트가 어느 줄인지 찍어 주니 시트를 고치면
표시도 사라진다.
