# PM 트래커 — 기록되는 웹사이트 (Vercel)

`pmtracker` HTML 을 **클라우드에 자동 저장되는 웹사이트**로 만든 것입니다.
이제 파일을 다운로드해서 덮어쓸 필요 없이, 입력한 값이 자동으로 저장되고
휴대폰·노트북 어디서 열어도 같은 내용이 보입니다.

## 어떻게 굴러가나

```
브라우저(index.html)
   ├─ 값이 바뀔 때마다 자동으로 /api/data 에 저장 (0.8초 묶음)
   └─ 열 때 /api/data 에서 최신 내용을 불러옴
        └─ /api/data (Vercel 서버리스 함수)
             └─ Upstash Redis(= Vercel 스토리지 "KV") 에 JSON 한 덩어리로 보관
```

- 서버가 잠깐 죽거나 오프라인이어도 **이 기기(localStorage)에는 즉시 저장**되어 화면이 유지됩니다.
- 여러 기기에서 동시에 고치면 **마지막 저장이 이깁니다**(단일 사용자용이라 이 정도로 충분).
- 다른 기기에서 방금 고쳤다면 상단 **"☁ 새로고침"** 으로 최신 내용을 불러오세요.

## Vercel 배포 (처음 한 번만)

1. <https://vercel.com/new> 에서 이 리포지토리를 import 합니다.
2. **Root Directory 를 `pm-tracker` 로 지정합니다.** ← 이것만 놓치지 마세요.
   (Framework Preset 은 `Other` 로 자동 인식됩니다 — 빌드 설정은 건드릴 필요 없음)
3. **저장소(스토리지)를 붙입니다.** 프로젝트 대시보드 → **Storage** 탭 →
   **Create Database** → **Upstash for Redis** (= KV) 선택 → 만든 뒤
   **Connect to Project** 로 이 프로젝트에 연결합니다.
   - 연결하면 `KV_REST_API_URL`, `KV_REST_API_TOKEN` 환경변수가 **자동으로** 들어갑니다.
   - 코드는 이 두 값을 자동으로 읽습니다. 별도 설정 없음.
4. 스토리지를 붙인 뒤 **Deployments → 맨 위 배포의 ⋯ → Redeploy** 를 한 번 눌러
   환경변수가 반영된 상태로 다시 배포합니다.

끝입니다. 이후 접속하면 입력한 값이 자동으로 저장·동기화됩니다.

> **아직 스토리지를 안 붙였다면?** 화면은 정상적으로 뜨지만
> "서버에 연결 못함 — 이 기기에만 저장돼요" 로 표시되고, 그 기기 안에서만 저장됩니다.
> 위 3번을 마치고 새로고침하면 클라우드 저장이 켜집니다.

## 공개 여부

이 사이트는 **비밀번호 없이 공개**입니다(주소를 아는 사람은 누구나 볼 수 있음).
나중에 막고 싶으면 옆 `web` 프로젝트처럼 `middleware` 로 비밀번호 게이트를 걸 수
있습니다 — 필요하면 요청하세요.

## 로컬에서 보기

정적 파일이라 그냥 브라우저로 `index.html` 을 열어도 화면은 뜹니다(이 기기 저장만 동작).
클라우드 저장까지 로컬에서 확인하려면 Vercel CLI 가 편합니다:

```bash
cd pm-tracker
npm install
npx vercel dev      # http://localhost:3000  (환경변수는 vercel link 후 pull)
```

## 구성 파일

- `index.html` — 트래커 화면 전체(디자인·로직). 저장만 클라우드로 바뀜.
- `api/data.js` — 저장/불러오기 서버리스 함수 (GET/PUT).
- `package.json` — `@upstash/redis` 의존성.
